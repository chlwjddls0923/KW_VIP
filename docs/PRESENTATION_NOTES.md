## 1. 문제 (0:40)

- 휠체어에 단 PiPER 팔이 한국어 텍스트 명령('3층 버튼을 눌러줘')을 해석하고, head 카메라 RGB-D로 버튼을 찾아 스스로 누른다(MuJoCo 시뮬레이션).
- 과제 조건: 같은 작업의 다른 표현 2개 이상 처리, 범위 밖·금지·불가능한 명령은 움직이지 않음, 외부 서버 없이 각자 PC에서 계산, 성공 = 목표 버튼 slide ≥ 10 mm.
- 출처: `README.md`, 계획서 1절

## 2. 구조 (0:50)

```
텍스트 → 명령 해석(kiwipiepy 형태소 + 규칙) → PRESS(n) / WAIT / REJECT / CLARIFY
                     │ PRESS일 때만
head 카메라 RGB-D → 버튼 인식(파란색 분할 → 라벨 → 깊이로 3D → 숫자 템플릿) → 층 확인
                     │
최소자승 IK(접근·누름 자세 미리 확인) → 위치 제어로 누르기 → 후퇴
```

| 부분 | 핵심 | 코드 |
|---|---|---|
| 해석 | 형태소 → 사건(누르기·이동·대기·부정) → 점수 → 판정 | `src/assist/nlu.py` |
| 인식 | HSV 분할, 라벨 픽셀, SVD 평면, 32×32 ZNCC(점수 ≥ 0.5, 여유 ≥ 0.03) | `src/assist/perception.py:91` |
| 동작 | 버튼 앞 8 cm → 법선 방향 직선 25 mm 깊이 → 후퇴 | `src/assist/motion.py:86` |

학습한 모델은 없다. 사전 학습 모델은 kiwipiepy(형태소 분리에만 씀)뿐이다.

## 부록: 팀원이 설명할 수 있어야 하는 네 질문

**1. 관측 데이터는 무엇인가.**
head 카메라(`head_rgb`) 한 대의 1280×960 RGB와 깊이 영상(광축 방향 거리, m), 그리고 카메라의 화각(fovy 72°)·위치·자세다(`src/assist/camera.py:43` `capture`, `camera.py:11` `Frame`).
여기에 패널 숫자 그림에서 만든 32×32 템플릿을 더한다(`perception.py:43`).
인식(`perception.py:91` `detect`)은 파란 버튼을 색으로 나누고, 라벨 픽셀을 깊이로 3D 점으로 바꾼다. 평면을 맞춰 라벨 중심과 패널 법선을 구한 뒤, 정면으로 편 패치를 템플릿과 비교해 층을 읽는다.
시뮬레이터 정답(버튼 위치·층 이름)은 채점에만 쓴다(`scene.py:220` `truth`).

**2. 텍스트는 동작에 어떻게 영향을 주는가.**
`nlu.py`가 kiwipiepy로 형태소를 나눈다(`nlu.py:242` `tokenize`). 층 표현을 읽고, 누르기·이동·대기 낱말과 부정·과거·조건을 사건으로 만든다.
사건마다 PRESS·WAIT·OTHER 점수를 더하는데, 뒤쪽 서술어일수록 무게를 크게 둔다. 판정은 PRESS(n)/WAIT/REJECT/CLARIFY다(`nlu.py:363`).
PRESS가 아니면 팔은 움직이지 않는다. PRESS(n)이면 인식된 층 목록에 n이 있는지 확인하고(`nlu.py:381` `ground`), n층 라벨의 중심과 법선을 동작 목표로 넘긴다(`pipeline.py:94`).
그래서 텍스트는 '움직일지'와 '어느 버튼을 목표로 할지'를 정한다. 궤적은 매번 인식한 위치로 계산한다.

**3. 출력은 어떤 관절 명령으로 바뀌는가.**
`motion.py:86` `plan_press`가 라벨 중심 c와 법선 n에서 접근 자세(버튼 앞 8 cm)와 누름 자세(라벨 면보다 25 mm 안쪽)를 정한다.
`ik.py:50` `IK.solve`(관절 한계를 넣은 최소자승, 위치 우선)로 관절각을 구하고, 움직이기 전에 두 자세 모두 오차 1 mm 이내인지 확인한다.
관찰 → 접근은 관절 공간 5차 보간 2초, 접근 → 누름은 법선 방향 직선 0.03 m/s다. 0.02초마다 목표 관절각 6개를 위치 제어 액추에이터의 `data.ctrl`에 쓴다(`motion.py:51` `tick`).
버튼은 손목 캡슐이 물리 접촉으로 민다.

**4. 성공률은 어떻게 계산했는가.**
공식 20회의 시드와 조건을 `data/eval_protocol.json`에 먼저 적고 커밋한 뒤 실행했다(`protocol.py:61`, `protocol.py:71`).
누르기 시행은 30초 안에 목표 버튼 slide ≥ 10 mm이고 다른 버튼이 모두 < 10 mm이면 성공이다. 움직이면 안 되는 시행은 관절 변화 < 0.02 rad, 버튼 < 1 mm이고 행동 분류가 맞으면 성공이다(`protocol.py:115` `judge`).
실패한 시행도 모두 `trials.csv`에 남기고(`pipeline.py:164` `run_trial`), 성공 수/시행 수와 Wilson 95% 구간을 계산한다(`protocol.py:144`). `scripts/eval.py summary`가 `results/summary.md`를 만든다.
